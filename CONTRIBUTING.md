# Участие в развитии проекта

**Valheim — Зал трофеев** — открытый фанатский веб-проект. Исправления, предложения по доступности, качеству интерфейса, переводу и игровым данным приветствуются.

## Сообщения об ошибках

Для ошибок и предложений используется [GitHub Issues](https://github.com/SergoAlexeev/valheim-trophies/issues). Полезны:

- описание наблюдаемого и ожидаемого поведения
- браузер, тип устройства и ширина экрана, если ошибка связана с интерфейсом
- название трофея и версия Valheim, если ошибка касается игровых данных
- шаги воспроизведения и, при необходимости, скриншот без персональных данных
- ссылка на проверяемый источник при предложении исправить название, вероятность или биом

## Изменения кода

Изменения можно предложить через pull request с кратким описанием цели и проверок. Проект использует обычные **HTML, CSS и JavaScript**, без фреймворков и серверной базы данных.

При подготовке изменения следует проверить релевантные сценарии: поиск и фильтрацию, переключение режимов, отметки трофеев, экспорт и импорт JSON, карточки на широком и узком экранах. При изменениях интерфейса важны клавиатурное управление, читаемость и мобильные состояния. Для изменений PWA необходимо учитывать механизм кэширования `sw.js`.

Обратная совместимость сохранённых коллекций важна: идентификаторы трофеев, ключ `localStorage` и структура JSON-архива не должны меняться без предусмотренной миграции.

- Присылаемые изменения должны быть оригинальными или использовать материалы, права на которые позволяют их включение в проект

- Изменения игровых сведений должны сопровождаться проверяемым источником и указанием версии игры
- Предлагая вклад в проект, автор подтверждает наличие необходимых прав и согласие на распространение своего вклада на условиях [MIT](LICENSE), если не согласовано иное
