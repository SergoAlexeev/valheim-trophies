# Valheim — Зал трофеев

Русскоязычный **статический сайт** для учёта трофеев Valheim. Включает 69 трофеев, тир-лист по редкости, фильтрацию по биомам, поиск, просмотр карточек, отметки найденного и резервное копирование прогресса JSON.

## Содержимое

- `index.html` — главная страница
- `assets/css/styles.css` — оформление
- `assets/js/app.js` — каталог и логика
- `assets/icons/` — иконки сайта и изображение для публикаций
- `manifest.webmanifest` — поддержка установки на устройство
- `sw.js` — офлайн-кэш интерфейса (на HTTPS)
- `.nojekyll` — корректная публикация на GitHub Pages

Не требуется Node.js, npm, база данных или серверный PHP.

## Быстрый запуск

Распакуйте ZIP и откройте `index.html` в браузере. Для полноценной проверки работы PWA, сервис-воркера и установки сайта запустите локальный HTTP-сервер в папке проекта:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000/`.

## Бесплатная публикация: GitHub Pages

1. Создайте **отдельный публичный** репозиторий GitHub, например `valheim-trophies` (не используйте репозиторий другого проекта).
2. Загрузите все файлы и папки из архива в **корень** репозитория — файл `index.html` должен находиться в корне, а не внутри дополнительной папки.
3. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветка `main`, папка `/(root)` и сохраните.
4. После публикации откройте адрес вида `https://ВАШ-ЛОГИН.github.io/valheim-trophies/`.

Загрузка GitHub Pages и выдача адреса зависят от настроек GitHub; этот архив не размещает сайт автоматически.

## Публикация на REG.RU или другом хостинге

Загрузите **содержимое** архива в публичную папку выбранного домена или подкаталога, например `/valheim/`, и откройте URL соответствующего каталога. Убедитесь, что веб-сервер отдаёт `manifest.webmanifest` и JS/CSS файлы, а сайт работает по HTTPS.

Для подкаталога ничего менять в путях не нужно: проект использует относительные ссылки `./`.

## Данные и приватность

- Отметки о найденных трофеях автоматически сохраняются **локально в браузере на этом домене** (localStorage)
- Никакие аккаунты, регистрации, трекеры и серверная база данных не предусмотрены
- При смене устройства, домена, браузера или при переходе с `file://` на `https://` используйте кнопку **«Сохранить прогресс»**, затем **«Загрузить прогресс»** на новом сайте
- Трофейные изображения подгружаются по сети из документации Jötunn; без подключения к интернету они могут быть недоступны даже при установленном приложении. Интерфейс после первого посещения по HTTPS кэшируется для офлайн-использования

## Настройка перед публикацией

- Укажите окончательный домен — при необходимости добавьте `canonical` и абсолютный `og:image` со ссылкой на `assets/icons/share-preview.png`
- В `index.html` можно изменить заголовок, описание и текст страницы
- Каталог трофеев хранится в константе `TROPHIES` файла `assets/js/app.js`; после изменения файлов PWA на хостинге обновите номер `SHELL_CACHE` в `sw.js`, чтобы посетители получили свежую версию

## Уточнение по данным

Базовый набор из предыдущей версии справочника содержит 69 трофеев для Valheim 1.0.21. Редкость — по заявленному базовому шансу выпадения, а не оценка силы врага. Фактические игровые механики могут отличаться; перед публикацией проекта как справочника рекомендуется перепроверить данные после обновлений игры.
