# Valheim — Зал трофеев

**Русскоязычный неофициальный справочник и трекер коллекции трофеев Valheim.** В каталоге — 69 трофеев для версии игры **1.0.21**, изображения предметов и существ, биомы, базовые шансы выпадения и учёт найденного.

**[Открыть сайт](https://sergoalexeev.github.io/valheim-trophies/)** · [Источники и права](https://sergoalexeev.github.io/valheim-trophies/sources.html) · [Сообщить об ошибке](https://github.com/SergoAlexeev/valheim-trophies/issues)

> Фанатский проект. Не связан с разработчиком Valheim — Iron Gate AB — или издателем Coffee Stain Publishing AB и не является официальным ресурсом игры.

## Возможности

- **69 трофеев из 9 биомов** с русскими названиями, английскими именами существ и игровыми изображениями
- **Два способа просмотра:** тир-лист по редкости и каталог по биомам
- **Ранги редкости:** S (5%), A (10%), B (15%), C (30–33%), D (50%) и ★ (100%). Ранг отражает шанс выпадения, **не силу противника**
- **Поиск и фильтры:** по названию, существу, биому, наличию трофея и главным боссам
- **Подробная карточка:** изображение трофея и существа, биом, базовый шанс, ранг, игровой идентификатор и пояснение механики выпадения
- **Личная коллекция:** отметки «Найдено», общая статистика, прогресс по редким трофеям и боссам
- **Резервная копия:** сохранение и восстановление отметок через JSON-файл
- **Адаптивный интерфейс и PWA:** работа в браузере на компьютере и телефоне; установка на устройство, если она поддерживается браузером

## Работа с сайтом

| Действие | Как это работает |
| --- | --- |
| Просмотр каталога | Переключатели **«Тир-лист»** и **«По биомам»** меняют группировку карточек |
| Поиск | Поле поиска находит трофеи по русскому названию, имени существа и другим данным каталога |
| Фильтрация | Меню **«Все биомы»** и **«Все трофеи»** ограничивают отображаемый список. Доступен отбор найденных, ненайденных и трофеев главных боссов |
| Просмотр трофея | Кнопка информации открывает карточку с изображениями и справочными характеристиками |
| Отметка находки | Чекбокс или кнопка **«Отметить»** меняют состояние трофея. Повторное нажатие снимает отметку |
| Статистика | Счётчики и процент заполнения обновляются автоматически |
| Сброс | **«Сбросить отметки»** очищает коллекцию после подтверждения; действие не отменяется автоматически |
| Установка | **«Установить сайт»** появляется только в браузерах, поддерживающих установку приложения |

По умолчанию отметки сохраняются автоматически в **localStorage текущего браузера и адреса сайта**. Учётная запись не требуется, синхронизация между устройствами не предусмотрена.

### Перенос коллекции и архив JSON

Кнопка **«Сохранить прогресс»** выгружает резервную копию отметок в файл `valheim-trophies-ГГГГ-ММ-ДД.json`. Кнопка **«Загрузить прогресс»** читает этот файл и, после подтверждения, **полностью заменяет** текущие отметки импортированными.

Резервная копия содержит только служебные поля формата, дату экспорта и идентификаторы отмеченных трофеев. Пример структуры:

```json
{
  "app": "valheim-trophy-hall",
  "formatVersion": 1,
  "gameVersion": "1.0.21",
  "exportedAt": "2026-11-20T07:00:00.000Z",
  "collected": [
    "boar-trophy",
    "greydwarf-trophy"
  ]
}
```

Допускается также импорт простого JSON-массива идентификаторов. Для импорта действуют ограничения: размер файла до **200 КБ** и массив до **200 элементов**. Повторяющиеся идентификаторы удаляются; неизвестные каталогу значения игнорируются.

JSON-файл — **архив прогресса этого сайта**, а не сохранение игрового мира или персонажа Valheim. Он не взаимодействует со Steam.

## Справочные данные

Каталог зафиксирован для **Valheim 1.0.21**. Версия игры указана для контекста; содержимое сайта не обновляется автоматически вместе с Valheim.

Базовые проценты выпадения носят справочный характер. Для некоторых редких трофеев игра использует счётчик подходящих убийств вместо независимой проверки шанса при каждом убийстве. В подробных карточках приведено пояснение этой механики. Звёздность существ и обновления игры могут влиять на фактические условия получения трофеев.

Исходные справочники: [Valheim Database — трофеи](https://valheimdb.com/trophies), [Jötunn — каталог предметов](https://valheim-modding.github.io/Jotunn/data/objects/item-list.html). Подробная информация об источниках и правообладателях — на странице [«Источники и права»](https://sergoalexeev.github.io/valheim-trophies/sources.html).

## Техническая структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Основной интерфейс и метаданные страницы |
| `assets/css/styles.css` | Стили, адаптивность, анимации и состояния элементов |
| `assets/js/app.js` | Данные каталога, поиск, фильтрация, карточки, прогресс и JSON-импорт/экспорт |
| `assets/icons/` | Favicon, иконки устанавливаемого приложения и изображение предпросмотра |
| `sources.html` | Публичная информация об источниках, правах и неофициальном статусе |
| `manifest.webmanifest` | Метаданные устанавливаемого веб-приложения |
| `sw.js` | Кэш интерфейса для PWA |

Проект реализован на **HTML, CSS и JavaScript** без фреймворков, сборщика, серверного приложения и базы данных. Данные трофеев входят в `assets/js/app.js`.

Установка PWA и кэш интерфейса зависят от поддержки браузера и безопасного контекста (HTTPS). Изображения трофеев и существ загружаются с внешнего ресурса **Jötunn / Valheim-Modding** и могут быть недоступны без сетевого подключения. Экспорт коллекции выполняется средствами браузера без передачи отметок на сервер проекта.
